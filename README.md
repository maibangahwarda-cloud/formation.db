Pourquoi certaines colonnes valent-elles NULL avec un LEFT JOIN ?
certaines colonnes valent null lorsque les informations de la table n'ont pas de concordances.

INNER JOIN ne garde que les lignes qui ont une correspondance dans les deux tables LEFT JOIN garde toutes les lignes de la table de gauche avec ou sans correspondance.
